# Umar Aslam | Frontend Developer Portfolio

A modern, fully responsive personal portfolio built for **MTech Solutions Frontend Development Internship (Batch 01, Task 01)**.

**Live site:** https://your-site.netlify.app *(replace with your deployed URL)*

## Technologies
- HTML5, CSS3 (Grid, Flexbox, custom properties, animations)
- Vanilla JavaScript (no frameworks)
- Font Awesome icons, Google Fonts (Sora, DM Sans)

## Features
- Sticky floating navbar with smooth scroll, active-section highlight, scroll progress bar and mobile menu
- Light and dark theme switch that remembers your choice
- Animated hero with typing effect, skills with animated bars, counters and scroll reveal
- 3 projects with live demos (included in this repo) and source links
- Services section and a contact form with frontend validation
- Footer with navigation, contact details and social links
- Responsive on mobile, tablet and desktop; keyboard focus styles and reduced-motion support
